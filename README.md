# Unknown Coffee Coffee Shop

A modern, responsive coffee shop website built with HTML5 and CSS3.

## Features

- Clean, modern design with a warm coffee-themed color palette
- Fully responsive layout for mobile, tablet, and desktop
- Navigation bar with smooth scrolling
- Home section with hero image and call-to-action
- Main feature section showcasing featured coffee products in cards
- About section telling the coffee shop's story
- Contact section with contact information and form
- Separate login page with form (frontend only)
- Hover animations and interactive elements
- Smooth scrolling between sections

## File Structure

```
brew-haven-coffee/
├── index.html          # Main website page (Home, Main Feature, About, Contact)
├── login.html          # Separate login page
├── style.css           # Stylesheet for the entire website
└── README.md           # This file
```

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- Google Fonts (via system font stack)

## How to View

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Navigate through the website using the navigation menu
4. Click "Login" to visit the login page

## Customization

- Replace placeholder images with actual coffee shop photos
- Update text content in HTML files
- Modify colors in the `:root` section of `style.css`
- Add more products to the Main Feature section by duplicating product cards

## Notes

- The login page is frontend-only. A functional login system requires backend authentication.
- All images are currently using placeholder URLs from via.placeholder.com
- The website uses CSS variables for easy theme customization

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers (responsive design)
